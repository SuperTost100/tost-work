Round 1: three ways to organise the work

These are wireframes. They compare where the work lives and how you follow it, so the look is plain on purpose and nothing behind the buttons works. Each one has the same screens with the same fake data: Giulia runs a small consulting studio and has four projects. Yellow notes explain the choice behind a screen, and the dashed bar at the bottom moves between screens.

A · Desk

Projects and their tasks in a sidebar, the open task in the middle with its plan, and the files it made on the right. Closest to Codex and T3 Code, without the code.

Bets on: a list you scan. Best when someone runs many small tasks.

Open A

B · Document

Each task is a page. You write the brief at the top and the result is written below it while you watch. Follow-ups are comments on the text. Quick edit shows changes to accept or reject, like track changes.

Bets on: reading the output, not the process. Best for people who live in Word and Google Docs.

Open B

C · Board

Each project is a board and every piece of work is a card. Opening a card shows the brief, the checklist and the files without leaving the board. Jobs have a week view.

Bets on: seeing everything at once. Closest to Paperclip, and the one that grows best into Advanced.

Open C

The same in all three

  • Everything happens inside a project, which is a folder plus instructions plus skills. The only exception is quick edit: drop one file and say what to change.
  • A running task shows its plan and the files it creates. Chat exists, but in a side tab.
  • When the agent wants to overwrite a file or has a question, the task moves to "Needs you" with the buttons right there.
  • Model and reasoning effort use their real names.
  • Skills have a form and the raw SKILL.md, and can be made from a finished task.
  • A job is a saved task with a schedule, and each run becomes a normal task.

What to tell me after looking

  1. Which direction feels closest, or which parts of each to combine. Mixing is fine: for example, A's layout with B's live result and C's week view for jobs.
  2. Does a running task show the right things: brief, plan, files, chat in a tab? What's missing or too much?
  3. Is quick edit right as the only chat? Should it give back a new file (A and C) or changes to accept (B)?
  4. Is the board home (C), a view you visit (A), or a filter over pages (B)?
  5. Anything a course participant would get stuck on in the first five minutes.

Laptop screens show these best. On a phone they open zoomed out.
