Writing while the AI works: three ways

In each option the AI is working. Type something in the box and send it: the message waits. Then press "Fine del turno" to see it go to the AI. Every option uses one waiting message: writing again while it waits adds to the same message. Pick a letter.

A · A waiting bubble at the end of the chat

The message shows where it will end up, as your next bubble, drawn with a dashed border until it's sent. Under it you can edit it or take it back. The box stays empty and ready for more.

B · A strip on top of the task box

The waiting message sits in one line at the top of the box, as Codex and T3 Code do. The chat only shows what the AI has received, and the strip goes away when the turn ends.

C · The text stays in the box

Nothing new on screen. While the AI works, the send button turns into a clock: pressing it books the text for the end of the turn, and the text stays in the box, where you can still change it.
